# fielding_dissertation_ja

Roy Fielding の論文、**Architectural Styles and the Design of Network-based Software Architectures** の日本語機械翻訳版です。REST論文として広く知られています。

## 概要

- この翻訳は機械翻訳によるもので、非公式です
- 正確な内容については必ず原文を参照してください
- REST アーキテクチャの基礎となる重要な論文の理解を助けることを目的としています
